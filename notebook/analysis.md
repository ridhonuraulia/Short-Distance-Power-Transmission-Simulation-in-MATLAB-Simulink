Simulation Analysis Notes
Objective
This simulation is used to study short-distance power transmission using MATLAB Simulink.

What to Observe
Phasor behavior in the transmission system
Output voltage
Transmission response under the given topology
Interpretation
The system shows how electrical power can be transmitted over a short distance and analyzed using a simple transmission model.

Lecturer-Provided Topology
The topology used in this simulation was provided by the lecturer.
This repository focuses only on analyzing and simulating the system, not on designing the original circuit.

Possible Extension
If a long-distance transmission model is needed, an additional transformer can be placed at the junction:

step-up transformer before transmission
step-down transformer after transmission
This helps simulate a higher-voltage transmission path more realistically.
